 # Пример: как работает ИИ-агент

Минимальный агент без фреймворков — только библиотека `ollama` и цикл
на несколько строк. Цель примера — показать, что «агент» это не магия,
а **LLM + инструменты + цикл**.

## Что показывает пример

| Часть агента | Где в коде (`agent.py`) |
|---|---|
| Системный промпт | `SYSTEM_PROMPT`, первое сообщение с ролью `system` |
| Инструменты | функции `get_weather`, `calculate` |
| Решение вызвать инструмент | `message.tool_calls` |
| Действие | вызов функции внутри цикла |
| Наблюдение | сообщение с ролью `tool` |
| Память | список `messages`, который дополняется |
| Планирование (цикл) | `for step in range(...)` |
| Размышления | флаг `THINK`, поле `message.thinking` |

## Запуск

```bash
ollama serve            # в отдельном терминале
ollama pull qwen2.5:3b  # модель, обученная вызывать инструменты
pip install ollama
python agent.py
```

## Как это работает

Один шаг цикла — это один запрос к модели:

1. Отправляем модели историю сообщений (`messages`) и список инструментов (`tools`).
2. Модель отвечает одним из двух:
   - обычным текстом — это финальный ответ, цикл завершается;
   - запросом на вызов инструмента (`tool_calls`) — с именем функции и аргументами.
3. Если это запрос на инструмент, **мы сами** выполняем функцию, дописываем
   её результат в историю как сообщение роли `tool` и повторяем шаг.

Модель никогда не выполняет код сама — она лишь просит об этом. Всё, что
происходит между запросами, делает наш код. Именно поэтому принцип работы
агента виден целиком: он весь в функции `run_agent`.


## Выбор модели

- **Инструменты.** Нужна модель, обученная вызывать инструменты (тег `tools`
  в библиотеке ollama): `qwen2.5`, `llama3.1`, `mistral` и др.
  Маленькие модели (`qwen2.5:3b`) быстрее, но иногда ошибаются с аргументами;
  крупные (`llama3.1:8b`) надёжнее.
- **Размышления.** Режим `THINK = True` требует модель с тегом `thinking`
  (`qwen3`, `deepseek-r1`, `gpt-oss`). У обычных моделей оставьте `False`.

См. также [Малые языковые модели их области применения](../../NLP/small_llm.md)

## Почему тексты для модели на английском

Системный промпт, вопрос пользователя и результаты инструментов написаны
на английском: небольшие локальные модели заметно лучше следуют инструкциям
и вызывают инструменты на английском, чем на русском. Комментарии в коде и
подписи в выводе оставлены на русском — они адресованы человеку, а не модели.
