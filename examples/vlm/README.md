# Коротко vision LLM в Ollama

VLM (vision language model) — мультимодальная модель: принимает изображение и текст, возвращает текст. В отличие от детекторов и сегментаторов, у неё нет фиксированного списка классов — содержание ответа задаёт промпт. Это делает VLM универсальным инструментом: описание изображений, ответы на вопросы по картинке (Visual Question Answering, VQA), классификация с открытым словарём, распознавание текста.

Примеры небольших мультимодальных LLM во всех размерах:

| Модель | Размер | Особенности |
| --- | --- | --- |
| `qwen3.5:2b-q8_0` | 2.7 ГБ | основная для примеров, контекст 256K |
| `gemma4:e2b-it-qat` | 4.3 ГБ | второй вариант для сравнения описаний |
| `bonsai-2:4b` | 1.6 ГБ | ternary-веса: вдвое меньше 4-битных |
| `gemma4:31b-cloud` | облако | для слабых ноутбуков, код не меняется |
| `glm-ocr` | 2.7 ГБ | специальная модель для извлечения текста из изображений |


## Файлы в папке

- `vlm_captioning.py` — описание изображений: промпт управляет детальностью, сравнение двух моделей, VQA.
- `vlm_classification.py` — zero-shot классификация с открытым словарём: классы в промпте, структурированный вывод (JSON schema с `enum`).
- `../images/` — общая папка с тестовыми изображениями для всех примеров.
- `requirements.txt` — зависимости (`ollama`, `pillow`).

## Подготовка

Установить Ollama и скачать модель:

```
ollama pull qwen3.5:2b-q8_0
```

## Базовый вызов

```python
import ollama

response = ollama.chat(
    model="qwen3.5:2b-q8_0",
    messages=[{
        "role": "user",
        "content": "Опиши изображение двумя-тремя предложениями.",
        "images": ["../images/peoples_and_dog.jpg"],
    }],
    think=False,   # выключаем рассуждения перед ответом — быстрее
)
print(response.message.content)
```

Поле `images` принимает путь к файлу, байты или base64-строку; в REST API
изображение кодируется base64.

## Structured output

Параметр `format` принимает JSON-схему, и модель обязана вернуть JSON по ней.
Для классификации поле `enum` фиксирует допустимые классы:

```python
schema = {
    "type": "object",
    "properties": {"class": {"type": "string", "enum": ["dog", "person"]}},
    "required": ["class"],
}
response = ollama.chat(model=..., messages=..., format=schema)
result = json.loads(response.message.content)
```

## Отличие от CLIP

CLIP вычисляет похожесть изображения с текстами всех классов и даёт оценку
для каждой метки набора — быстрый проход энкодером. VLM генерирует ответ:
медленнее, зато классы можно формулировать произвольно («сделано зимой»,
«люди в деловой одежде»), и модель обосновывает решение. Уверенность VLM
не откалибрована, как вероятности CLIP, а структурированный вывод страхует
от выхода за заданный список классов.
