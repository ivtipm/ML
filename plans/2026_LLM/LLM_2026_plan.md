# Курс «LLM: большие языковые модели»


## О курсе

Курс посвящён обработке естественного языка и большим языковым моделям. Начинаем с практики: промпт-инжиниринг и агентские системы — то, с чем вы уже сталкивались в работе с LLM. Затем разбираемся, как это устроено изнутри: трансформеры, LLM, предобученные модели. Завершаем построением систем на основе LLM: RAG, агентские системы для прикладных задач, оценка и эксплуатация.

9 лекций и 9 практик, по 1.5 астрономических часа

## Результаты освоения курса

После курса вы сможете:

- составлять эффективные промпты и критически оценивать ответы LLM;
- применять LLM к задачам своей магистерской работы;
- использовать ИИ агентов в IDE;
- выбирать и разворачивать локальные LLM;
- объяснять, как устроены трансформеры и LLM, и чем отличаются основные семейства моделей (BERT, GPT и другие);
- дообучать предобученные модели (в том числе через адаптеры);
- проектировать, реализовывать и оценивать RAG-системы;
- строить агентские системы для прикладных задач (анализ данных, обработка документов и т.п.);
- оценивать качество LLM-приложений, понимать их ограничения и риски.


## Связь с другими курсами

Курс опирается на уже пройденные курсы:

- «Подготовка данных»: представление текста (TF-IDF, BM25, эмбеддинги), пайплайны, работа с датасетами;
- «Классическое машинное обучение»: классификация, метрики, кросс-валидация, пайплайны sklearn.


## Основные темы

Курс построен «от практики к теории»: сначала промпт-инжиниринг, локальный запуск и агенты, затем устройство моделей, в конце — предобученные модели и построение систем на основе LLM: RAG, агентские системы, оценка и эксплуатация.

### Тема 1. Промпт-инжиниринг

1. LLM.  основные сервисы и модели
   - сравнение сервисов, выбор модели под задачу
   - слайды: https://docs.google.com/presentation/d/1y_R99DlMprkxNmDjhekuONVODyO0CUCpOD2AmyMaZhs/edit?usp=sharing
   - сравнение сервисов с LLM: https://github.com/ivtipm/ML/blob/d40a2afc57ff0da4400be7ddd0a5ba41ddc6bf53/slides%20etc/%D0%A2%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D0%B0%20%D0%98%D0%98-%D0%B0%D1%81%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BD%D1%82%D0%BE%D0%B2.pdf
2. Что такое промпт
   - структура: роль, задача, контекст, требования к ответу
   - системный и пользовательский промпты
3. Техники промпт-инжиниринга
   - zero-shot и few-shot
   - chain-of-thought, self-consistency
   - структурированный вывод (JSON, таблицы)
4. Параметры генерации
   - temperature, top-p, top-k, ограничение длины
   - как параметры влияют на ответ
5. Оценка ответов LLM
   - галлюцинации и как их замечать
   - воспроизводимость, сравнение моделей
6. Безопасность
   - prompt injection, приватность данных
7. Практика: задание 1 — [tasks/task_LLM_use.md](tasks/task_LLM_use.md)



### Тема 2. Агенты на основе LLM

1. Концепция агентов
   - LLM + инструменты + память + планирование
   - чем агент отличается от простого чата
2. ReAct
   - цикл «мысль → действие → наблюдение»
3. Инструменты и function calling
   - поиск, калькулятор, выполнение кода, работа с файлами
4. Фреймворки
   - LangChain: chains, tools, memory
   - LlamaIndex, AutoGen, CrewAI
5. Агентские системы и вайбкодинг
   - Claude Code, Codex, Zed, VS Code
   - навыки (skills), файлы инструкций (.agents, .claude)


### Тема 3. Локальные LLM: запуск и настройка

1. Зачем запускать LLM локально
   - приватность, стоимость, оффлайн-работа
   - ограничения: железо, скорость
2. Выбор модели
   - размер модели и требования к памяти
   - квантование: GGUF, GPTQ, AWQ
   - как понять, какая модель подойдёт под задачу и железо
3. Инструменты для запуска
   - Ollama, llama.cpp, LM Studio
   - сравнение инструментов
4. Настройка работы модели
   - параметры генерации: temperature, top-p, top-k, ограничение длины
   - системный промпт и шаблоны
   - стриминг
5. API
   - API Ollama, OpenAI-совместимые API
   - подключение из кода и сторонних приложений
6. Hugging Face
   - hub, datasets, transformers, pipelines
   - скачивание и запуск моделей


### Тема 4. Трансформеры

1. Проблемы рекуррентных сетей
   - последовательная обработка, долгие зависимости (кратко; подробно — курс «Нейросети»)
2. Внимание
   - идея: какие части входа важны для ответа
   - self-attention: запросы, ключи, значения (QKV)
   - multi-head attention
3. Позиционные эмбеддинги
   - зачем нужны, как устроены
4. Архитектура трансформера
   - encoder, decoder, encoder-decoder
   - остаточные связи, нормализация слоёв
5. Первые трансформеры и их наследники
   - BERT (encoder), GPT (decoder), T5 (encoder-decoder)

### Тема 5. Large Language Models

1. Что такое LLM
   - масштаб моделей, scaling laws
   - чем LLM отличается от «просто» трансформера
2. Типы LLM
   - encoder-only, decoder-only, encoder-decoder
   - авторегрессионная генерация
3. Основные семейства моделей
   - GPT, BERT, Llama, Mistral, Qwen, DeepSeek
   - чем отличаются: архитектура, способ обучения, размер, лицензии
4. Как обучают LLM
   - pretraining: MLM и CLM
   - fine-tuning, инструктивные модели, RLHF
   - адаптеры: LoRA, QLoRA — дообучение без больших ресурсов
5. Контекстное окно
   - что это, почему важно, длинные контексты


### Тема 6. Предобученные модели. Классификация текста с BERT

1. Transfer learning в NLP
   - предобученные модели как отправная точка
   - связь с курсом «Нейросети»
2. Fine-tuning и адаптеры
   - полное дообучение vs LoRA
   - извлечение признаков (эмбеддинги)
3. Классификация текста
   - постановка задачи, метрики (точность, F1)
   - BERT: токенизация, входные представления, [CLS]-токен


### Тема 7. RAG: от прототипа к продакшену

1. Когда нужен RAG
   - ограничения LLM без внешнего контекста
   - выбор подхода: промптинг vs RAG vs дообучение vs агенты
2. Индексация
   - чанкинг: размер, перекрытие, структурные чанки по документам
   - эмбеддинги для поиска: sentence transformers, кросс-энкодеры
   - метаданные и фильтрация
3. Поиск
   - векторный поиск: ANN, HNSW
   - гибридный поиск: BM25 + dense
   - reranking, query rewriting
4. Векторные БД: FAISS, Chroma, Qdrant
   - сравнение, масштабирование
5. Генерация
   - промпт с контекстом и источниками, «отвечай по контексту»
6. Оценка качества RAG
   - RAG-триада: context relevance, groundedness, answer relevance
   - RAGAS, метрики ретривера (MRR, NDCG, recall)


### Тема 8. Агентские системы для прикладных задач

1. От чата к агенту
   - LLM + инструменты + память + планирование
   - когда агенты нужны: многошаговые задачи, взаимодействие с внешним миром
2. Планирование
   - ReAct, «план → проверка → исполнение», self-consistency
3. Память
   - краткосрочная (диалог), долгосрочная (векторные БД, базы знаний)
   - рабочие заметки (scratchpad)
4. Мультиагентные системы
   - паттерны: оркестратор-воркеры, конвейер, дебаты
   - фреймворки: LangGraph, AutoGen, CrewAI
5. Прикладные кейсы
   - агент-аналитик данных, deep research, обработка документов
   - поддержка пользователей, веб-автоматизация
6. MCP (Model Context Protocol) — стандартизация инструментов
7. Оценка агентов
   - выполнение задачи, траектории, бенчмарки


### Тема 9. Оценка, безопасность и эксплуатация LLM-систем

1. Оценка LLM-приложений
   - метрики и бенчмарки
   - LLM-as-a-judge и его ограничения
   - наборы тестов (evals), симулированные пользователи
2. Оркестрация и наблюдаемость
   - трассировка: LangSmith, Langfuse; логирование, мониторинг
3. Сервинг и оптимизация инференса
   - vLLM, KV-кэш, батчинг
   - квантизация; стоимость и латентность
4. Безопасность
   - prompt injection, red teaming, приватность, guardrails
5. Жизненный цикл
   - обратная связь от пользователей, human-in-the-loop
   - итеративное улучшение: промптинг → RAG → дообучение
