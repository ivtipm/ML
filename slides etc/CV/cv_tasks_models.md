# Задачи компьютерного зрения: вход и выход

Обозначения:

- `[x_1, x_2, ...]` — список; `(a, b)` — кортеж; `[(a, b), ...]` — список кортежей, где каждый кортеж — один объект
- `изображение` — тензор H×W×3; `bbox` — рамка (x1, y1, x2, y2); `mask` — карта H×W; `conf` — уверенность; `вектор` — embedding фиксированной длины

| Задача | Вход | Выход | Модели (примеры) |
|---|---|---|---|
| Классификация | изображение | `class` | CNN (ResNet), ViT, YOLO26-cls |
| Zero-shot классификация | изображение, `[текстовая_метка_1, текстовая_метка_2, ...]` | `[(class, prob), ...]` | CLIP, SigLIP 2 |
| Детекция | изображение | `[(conf, bbox, class_probs), ...]` | YOLO26, RT-DETR, D-FINE, RF-DETR |
| Open-vocabulary детекция | изображение, `текст_промпт` | `[(conf, bbox, text_label), ...]` | Grounding DINO, YOLOE, YOLO-World |
| Семантическая сегментация | изображение | `mask` — класс для каждого пикселя | SegFormer, DeepLabV3+, Mask2Former |
| Instance-сегментация | изображение | `[(conf, mask, class), ...]` | YOLO26-seg, Mask2Former |
| Promptable-сегментация | изображение, `промпт` (точка \| рамка \| маска) | `[(mask, conf), ...]` | SAM 2, SAM 3 |
| Open-vocabulary сегментация | изображение, `текст_промпт` | `[(conf, mask, text_label), ...]` | YOLOE, SAM 3; пайплайн Grounded SAM = Grounding DINO + SAM 2 |
| Описание изображения (captioning) | изображение | `текст` | VLM: Qwen3-VL, Gemma, Florence-2 |
| VQA (вопрос по изображению) | изображение, `вопрос` | `текст` | VLM: Qwen3-VL, Gemma |
| Извлечение признаков | изображение | `вектор` | DINOv3, CLIP, SigLIP 2 |
| OCR | изображение | `текст` или `[(text, bbox), ...]` | модели: PaddleOCR-VL, GLM-OCR, DeepSeek-OCR; библиотеки: Tesseract, EasyOCR |
| Оценка позы (ключевые точки) | изображение | `[(keypoints, conf), ...]` — на человека | YOLO26-pose, RTMPose, ViTPose |
| Трекинг | видео | по кадрам: `[(track_id, bbox, class), ...]` | YOLO + ByteTrack / BoT-SORT |
| Распознавание лиц | изображение | детекция → `вектор` → сравнение с базой | детектор (RetinaFace) + ArcFace, AdaFace (InsightFace) |
| Оценка глубины | изображение | `depth_map` — H×W | Depth Anything V3, MiDaS |
| 3D-реконструкция по видео | набор фото или видео | `3D-модель` (облако точек, mesh) | Gaussian Splatting, NeRF |
| Восстановление 3D по одному фото | изображение | `depth_map` + камеры или `3D-модель` | DUSt3R, VGGT |

## Генеративные задачи

Отдельная группа: модель не анализирует изображение, а создаёт новое. Обозначения те же.

| Задача | Вход | Выход | Модели (примеры) |
|---|---|---|---|
| Генерация изображения по тексту | `текст` | `изображение` | открытые веса: FLUX.2, Qwen-Image, SDXL, SD 3.5; API: GPT Image 2.5, Nano Banana Pro, Seedream 4.5, Imagen 4 |
| Редактирование изображения | `изображение`, `инструкция` или `маска` | `изображение` | Qwen-Image-Edit, FLUX.1 Kontext, Nano Banana, ControlNet |
| Перенос стиля | `изображение`, `референс_стиля` | `изображение` | ControlNet, IP-Adapter, InstantStyle |
| Колоризация | ч/б `изображение` | цветное `изображение` | DDColor |
| Суперразрешение | `изображение` | `изображение` (большего разрешения) | Real-ESRGAN, SUPIR |
| Генерация видео | `текст` и/или `изображение` | `видео` | API: Veo 3.1, Kling 4.0, Seedance 2.5, Runway Gen-4.5; открытые веса: Wan 2.2, HunyuanVideo 1.5, LTX-2 |
| Генерация 3D-модели | `текст` или `изображение` | `3D-модель` (mesh, текстуры) | TRELLIS, TripoSR, Meshy |

Замечания к нотации:

- У детектора `conf` — общая уверенность на бокс, `class_probs` — вероятности по классам (у YOLO именно так). Если модель выдаёт сразу класс, `class_probs` вырождается в один элемент.
- Трекинг и распознавание лиц — не отдельный тип выхода, а надстройки: трекинг = детекция + связь боксов между кадрами (`track_id`), распознавание лиц = детекция + извлечение признаков + сравнение векторов.
- Promptable- и open-vocabulary-сегментация различаются промптом: у SAM он геометрический, и модель не знает класс объекта; у YOLOE и SAM 3 промпт текстовый.
- ArcFace и AdaFace — не архитектуры, а функции потерь для обучения энкодера. ArcFace (2019) — стандарт де-факто, AdaFace (2022) — её развитие для низкокачественных фото. На практике используют готовые энкодеры из InsightFace. С 2022 года парадигмальных сдвигов в распознавании лиц нет: новые работы (ViT-энкодеры, устойчивость к качеству, справедливость между группами) улучшают детали, а не меняют подход.
