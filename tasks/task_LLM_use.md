# Задание: Использование больших языковых моделей

Вы можете предложить свой вариант задания.

**Цель задания:**
Научиться основам промпт-инжиниринга, использования ИИ агентов в задачах изучения научных статей.

**Инструкция:**

1. **Изучите материал лекции и выбирете 2 или больше LLM (чата с LLM)**
   Ознакомьтесь с характеристиками больших языковых моделей, их видами, примерами, а также с рекомендациями по написанию запросов к LLM.
   - Слайды: https://docs.google.com/presentation/d/1y_R99DlMprkxNmDjhekuONVODyO0CUCpOD2AmyMaZhs/edit?slide=id.p#slide=id.p
   - См. запись лекции
   - Выбирайте современные LLM. Можно выбрать одну локальную LLM. Рекомендуется залогиниться на сайте с LLM, так как таким пользователям как правило доступны более продвинутые языковые модели, б*о*льшие лимиты на их использование и дополнительные настройки.
   - Выясните, можно ли на сайте выбирать конкретные LLM, как это, например, возможно на сайте https://chat.qwen.ai/. Если нет, то попробуйте иным способом выяснить версию LLM. Например напрямую спросите об этом в чате. Иногда название LLM указано в ситемном промпте, даже есть его нельзя посмотреть напрямую. Для надёжности повторите запрос в другом чате.
   - Известен ли размер контекстного окна?
   - Можно ли включить на сайте режим поиска в Интернете? Можно ли включить режим размышлений? Есть ли память? Можно ли просмотреть или изменить системный промпт и персональный промпт?
   - Можно ли редактировать промпты?

2. **Выберите научную статью, разбор которой будет полезен для вышей магистерской работы**
  Статья должна быть представленна pdf файлом. Для его чтения не должно требоваться распозновать скан текста.

3. **Составьте 1-2 запроса к LLM.**\
  - Например попросите пересказать содержание статьи или разобрать идеи, предлагаемые в статье.
  - Чтобы удобнее было анализировать ответы LLM формулируйте запросы так, чтобы ответы были компактными и легко сравнивались между моделями.
  - Запишите версию LLM (например Qwen3.8-Max), был ли включен режим размышления? Заданы ли другие параметры, влияющие на результат работы LLM? Например память, информацию из проекта (папки с чатами), системный промпт и т.д.
  - Оцените ответ. Соответствует ли он статье, есть ли в нём ошибки и галюцинации? Воспроизводися ли ответ в другом чате?
  - *Бонус: отдельно проверьте, на сколько хорошо в чате обрабатываются pdf файлы: доступны ли для LLM изображения? Понимает ли она их? Может ли воспроизвести формулы из статьи?*

4. **Улучшите запросы к LLM**
   - Выберите один из составленных вами запросов.
   - Попробуйте несколько вариантов его формулировки, чтобы получить наиболее полезный результат. Используйте структуру запроса: `Роль + Задача + Требования к ответу` или любой другой промпт с описанием вашей задачи.
   - Опишите, какие изменения вы внесли и как это повлияло на ответы модели.

5. **Используйте агентскую систему**
  Повторите п. 3 но в агентской системе. Например `Claude Code`, `Codex`, `Zed Agent` и др. В качестве LLM можете использовать бесплатные версии, которые предоставляют Ollama, Mistral или OpenRouter (могут быть пробелмы с достыпом из РФ).
  В качестве оболочки для агента можно наряду с консольными клиентами (например `Claude Code`) можно использовать IDE: Zed, VS Code и другие.

  Запишите название агента и LLM, какой уровень размышлений был включён, обращался ли агент к дополнительным инструментам, максимальный размер контекстного окна, использовались ли навыки (skills), был ли файл с инструкциями и правилами для агентов (например `.agents` или `.claude`).

6. **Сравните ответы разных LLM в разных чатах и агенской системе**
   - Используйте тот же запрос что и в п. 4 для двух или более различных LLM (например, ChatGPT и GigaChat).
   - Сравните полученные ответы из п.3,4,5 по таким параметрам, как полнота, точность и стиль изложения.
   - Сделайте выводы о том, какая модель оказалась более подходящей для вашей задачи.

7. **Подготовьте отчёт по всем пунктам этого задания**
В частности, приведите:
   - Название разобранной статьи, ссылку на статью
   - Примеры промптов и ответов на них
   - Описание процесса улучшения одного из запросов.
   - Сравнение ответов различных LLM по одному из запросов.
